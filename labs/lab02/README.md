# Лабораторна робота №2. ООП та аналіз журналів веб-сервера

## Опис проекту
У цій лабораторній роботі реалізовано:
1. **Завдання 1 (ООП)**: Систему контролю доступу з класами `User`, `Admin`, `Session`, `AuditLog` та `UserAccount`.
2. **Завдання 2 (Варіант 1)**: CLI-утиліту для розбору та аналізу Nginx/Apache Access Log з виявленням аномалій і сигнатур атак (SQLi, XSS, Directory Traversal).

## Структура модуля
- `task1.py` — Об'єктно-орієнтована модель безпеки.
- `task2.py` — Логіка розбору журналів та виявлення загроз.
- `main.py` — Головна точка входу (CLI).
- `data/` — Вхідні логи та згенеровані JSON-звіти.
